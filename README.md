# รวมร้าน · ระบบสต๊อก

เว็บแยกพื้นที่ทำงานตามร้านและสาขา ใช้ GitHub Pages + Supabase PostgreSQL/Auth

เว็บ: https://snokeynut.github.io/Stock/

## การใช้งาน

เข้าสู่ระบบ → เลือกร้าน → เลือกสาขา ข้อมูลสินค้า ผู้ขาย ประเภท ราคา เกณฑ์สั่งซื้อ และ Template แยกเป็นของแต่ละสาขา เพิ่มสินค้าในสาขาหนึ่งไม่เพิ่มให้สาขาอื่น

เมนู: ภาพรวม, สต๊อกสินค้า, รับสินค้าเข้า, เบิกสินค้า, เช็คสต๊อกรายวัน, แจ้งเตือนใกล้หมด, รายการสั่งซื้อ, ผู้ขาย, รายงาน, จัดการข้อมูลสาขา, Coming Soon

รับสินค้าเข้า เบิกสินค้า และเช็คสต๊อกเป็นหน้าว่างรอออกแบบใหม่ ยังไม่ใช่แบบฟอร์มสำหรับบันทึกงาน

ผู้ขายเก็บผู้ติดต่อ/LINE Name และคัดลอกข้อความสั่งซื้อได้ ไม่มีการส่ง LINE อัตโนมัติ

## สิทธิ์และพื้นที่เข้าถึง

- แอดมิน: ทุกพื้นที่ จัดการร้าน สาขา และสมาชิก
- ผู้จัดการร้าน: ทุกสาขาภายในร้านที่แอดมินมอบหมาย
- ผู้จัดการสาขา: สาขาที่แอดมินมอบหมาย
- พนักงาน: สาขาที่แอดมินมอบหมาย ไม่มีหน้ารายงานหรือจัดการข้อมูล
- ดูข้อมูลเท่านั้น: เฉพาะสาขาที่มอบหมาย ไม่มีสิทธิ์บันทึก

แอดมินตั้งค่าในเมนู ร้าน สาขา และผู้ใช้ → ผู้ใช้และสิทธิ์ ผู้ใช้ต้องมีบัญชีที่ยืนยันอีเมลแล้ว การสมัครเองไม่ให้สิทธิ์เข้าร้านโดยอัตโนมัติ

ฐานข้อมูลบังคับ RLS และตรวจสิทธิ์/ขอบเขตสาขาในทุกคำสั่งบันทึก ไม่มี service-role key ในเว็บ

## ไฟล์

- index.html: เว็บที่ build รวม React และ CSS แล้ว
- ruamran-stock-source.zip: codebase TypeScript พร้อม lockfile, migration และ tests ไม่มีสำเนาข้อมูลร้านหรือข้อมูลสำรองส่วนตัว
- .nojekyll: ใช้เผยแพร่ผ่าน GitHub Pages

## Build

แตก source zip → `npm ci` → `npm run build:pages` → อัปโหลด `pages-dist/index.html` ไป repository root
